# CSS Only Custom Alert Component

This example demonstrates "CSS-Only Custom Elements" by creating a reusable alert component using only HTML and CSS. It showcases how to define custom-looking HTML tags and style them with CSS, including variations based on attributes and pseudo-elements, without any JavaScript. This approach provides lightweight, performant UI components.

## Language

`html`

## How to Run

Open `index.html` in any modern web browser.
